# AMP Walking WAQ / Walk-to-run

状态 `AmpWalkingWAQ = 0x1100d`，对应 `kAmpWalkingWAQ`、`AmpWalkingWAQState` 和 `AmpWalkingWAQPolicyRunner`。
2026-10-30 更换为 walk-to-run 策略，保留原状态编号及键盘、手柄、DDS 入口。

## 接口与控制

模型为 `run_policy/cr1pro/policy/amp_policy/walktorun/policy_1030.onnx`，SHA256 为
`367b15131285e750d80792d99416ac7ccdb347ee918ac05cec24cbd2811d35b0`。
ONNX 实际接口为 float32 `obs[1,480] → actions[1,29]`，网络为 `ActorCritic` 的四层 actor。

训练参数以同目录 `env(15).yaml` 和 `agent(15).yaml` 为准：

- 单帧 96 维：机体角速度 3、投影重力 3、速度命令 3、关节相对默认角 29、关节速度 29、上一网络动作 29。
- 关节顺序使用 Isaac B2 的左右交错顺序，观测与 29 维动作均映射到 SDK 的腰／左臂／右臂／左腿／右腿排列。
- 输入为五帧历史，共 `5×96=480` 维，按时间从旧到新排列并包含当前帧，首帧重复填满历史；不再额外拼接当前帧，也没有步态相位观测。
- 角速度、重力、命令、位置和上一动作缩放为 1，关节速度缩放为 0.05；动作缩放为 0.25，观测与目标动作限幅为 ±100。
- 推理周期固定 20 ms（训练物理步长 `0.005 s × decimation 4`，对应 SDK 20 个 1 ms tick）；进入时立即完成首帧推理，每次重新进入都会先停止旧线程，再重置历史、上一动作与速度渐变。
- 29 个物理关节由策略控制，包括手臂；状态输出为有限 `31×5` 指令，两行虚拟头部为零。推理或加载故障退出到阻尼。
- 跑步时网络可能请求超出 SDK 踝关节限位的虚拟 PD 目标。状态通过现有 `BoundedPolicyCommand` 将位置、速度和前馈力矩约束在 SDK 范围内，并在电机力矩限制内保留原始 PD 请求的力矩；下游关节保护仍正常执行。
- 模型训练前后速度范围为 `[-0.5, 3.0] m/s`，SDK 运行时收紧为 `[-0.5, 2.0] m/s`；侧向范围为 `[-0.5, 0.5] m/s`、转向为 `[-1.57, 1.57] rad/s`。归一化输入先限幅至 ±1，再按每次推理 `[0.02, 0.02, 0.04]` 渐变，乘以上限 `[2.0, 0.5, 1.57]` 后按运行范围限幅；`SetCmdMaxVel` 可进一步收紧范围，无法突破前进 `2.0 m/s` 的上限。现有键盘输入层在 WAQ 状态对三个归一化分量限幅至 ±0.8，对应最高前进命令 `1.6 m/s`。

**资产参数来源：** 已与 `walktorun/env(15).yaml` 中的 `scene.robot.init_state.joint_pos` 和 `scene.robot.actuators` 核对：髋／膝／踝 pitch 为 `-0.15/0.3/-0.15`，肩 roll 为左右 `±0.2`，肘 pitch 为 `0.8`；腰 kp/kd 为 `350/15`，腿部 kp 为 `350/350/200/350/100/100`，kd 为 `10/10/5/10/5/5`，手臂 kp 为 `200/150/150/200/150/150/150`、kd 为 `5`。这些数值与原 runner 一致。

SDK 直接加载 `walktorun/policy_1030.onnx`。观测字段和历史初始化沿用 B2 训练环境的 CircularBuffer 约定。

## 状态切换

从以下任一状态发送 DDS `/MOTION_STATE` 的 `state = 0x1100d` 即可请求进入：

- AMP 准备 `0x20006` 或 AMP 行走准备 `0x7`。
- RL 站立 `0x1100b`、敬礼 `0x11013`、原 AMP 行走 `0x11` 或 MoE `0x1100c`。

WAQ 中可发送 `0x1100b` 返回 RL 站立、`0x11013` 进入敬礼、`0x11` 返回原 AMP 行走、`0x2` 进入阻尼；其他请求保持 WAQ。进入时已有安全故障或阻尼请求，不发送首帧策略动作。
`/STEER`、`/REAL_STEER` 的速度输入、两秒 DDS 速度超时处理与状态反馈均已接通。

键盘 `O` 从上述入口进入 WAQ，`V` 返回 RL 站立，`M` 返回原 AMP 行走，`R` 进入阻尼。
WAQ 中手柄 R1 返回 RL 站立，L2 返回原 AMP 行走；请求进入 WAQ 使用上面的 DDS 状态地址。
`W/S` 调整前进指令，`A/D` 侧移，`Q/E` 转向，`X` 停车。手臂由网络输出。
