# Motion Master：编译、部署与启动

本文记录当前键盘控制版本在 ARM 机器人上的标准启动流程。

## 1. 编译

在项目根目录执行：

```bash
mkdir -p build
cd build
cmake .. -DBUILD_PLATFORM=arm
make -j4
```


## 2. 打包

```bash
make package
ls -lh *.deb
```

> Deb 文件名包含版本号和构建时间。部署时请以 `ls` 实际输出的文件名为准。

## 3. 上传并安装

将生成的 Deb 包上传至机器人：

```bash
scp -O motion_master.v1.3.0+unknown.arm64.2611241446_pro_yj.deb user@10.21.33.103:~/yj

```

登录机器人后安装：

```bash
密码'
ssh user@10.21.33.103
sudo dpkg -i motion_master.v1.3.0+unknown.arm64.2611241446_pro_yj.deb
```

## 4. 启动机器人控制


```bash
sudo systemctl stop motion_master.service
sudo systemctl start imusense.service
/opt/robot/share/motion_master/scripts/run.sh


sudo systemctl restart motion_master.service

```

## 5. 手柄 App 状态流转

| App 按钮名称 | 内部目标状态 | 可从以下状态切入 | 切入后可切出至 | 说明 |
|---|---|---|---|---|
| 悬架起立 | `SuspendedStand 0x20006` | 待机、零位校准 | 开始运动、RL站立 | 悬架条件下的站立准备姿态 |
| 开始运动/RL | `RLControlMode 0x11` | 零位、悬架起立、RL站立 | RL站立、跑步、坐下、蹲下、待机 | 加载 `std_amp_2.onnx` 的普通 RL 控制 |
| RL站立 | `Restand 0x1100B` | 普通 RL、跑步、起立、蹲起站立 | 开始运动、跑步、蹲下、坐下、待机 | 双肘按来源状态选择 `+1.2` 或 `-0.4` |
| 跑步 | `Run 0x1100C` | 普通 RL、RL站立、起立、蹲起站立 | 开始运动、RL站立、蹲下、坐下、待机 | 原 NirenWalk 跑步策略 |
| 坐下 | `Stand2SitMimic 0x1100D` | 普通 RL、跑步、RL站立 | 起立、阻尼 | 训练默认双肘 `0.8` |
| 起立 | `Sit2StandMimic 0x1100E` | 完成坐下或待机蹲姿准备 | 开始运动、RL站立、跑步、坐下、阻尼 | 保持实测坐姿 |
| 蹲下 | `DunXia 0x1100F` | 普通 RL、跑步、RL站立、蹲起站立 | 蹲起站立、阻尼 | 训练默认双肘 `1.2` |
| 蹲起站立 | `ZhanLi 0x11010` | 完成蹲下 | 开始运动、RL站立、跑步、坐下、阻尼 | 训练默认双肘 `1.2` |

所有运动状态均可通过 `R` 请求进入 `JointDamping`；保护触发、AMP 推理失败同样会进入阻尼。`JointDamping` 保持 10 秒后自动返回待机。
注意每个状态机切入的前一个状态都是RL

### 正常展示流程（重点）

1. **悬架起立**
2. **开始运动**（普通 RL，加载 `std_amp_2.onnx`）
3. **RL → RL站立 → 手臂抬起/放下 → RL**
4. **RL → 坐下 → 起立 → RL**
5. **RL → 蹲下 → 蹲起站立 → RL**

## 6. 键盘状态切换  

| 按键 | 功能 |
| --- | --- |
| `X` | 待机时请求悬架起立 |
| `C` | 进入普通 RL 控制（`0x11`，加载 `std_amp_2.onnx`） |
| `V` | 进入 Run（`0x1100C`） |
| `T` | 从 RL、Run 或 RL站立进入坐下（`0x1100D`） |
| `Y` | 坐稳后请求起立（`0x1100E`） |
| `G` | 从 RL、Run 或 RL站立进入蹲下（`0x1100F`） |
| `H` | 蹲稳后进入蹲起站立（`0x11010`） |
| `Z` | 返回零位 |
| `R` | 在运动状态中请求进入关节阻尼 |
| `W` / `S` | 前进 / 后退；每次按键增加 / 减少 `0.1` 归一化速度 |
| `A` / `D` | 左移 / 右移；每次按键增加 / 减少 `0.1` 归一化速度 |
| `Q` / `E` | 逆时针 / 顺时针转向；每次按键增加 / 减少 `0.1` 归一化速度 |

普通 RL 的速度范围为前进 `vx` 最大 `1.2 m/s`、后退 `vx` 最小 `-0.6 m/s`、横移 `vy=±0.5 m/s`、转向 `wz=±1.0 rad/s`。Run、RL站立、坐下、起立、蹲下和蹲起站立的切换仍需等待上一个动作完成，避免在动作过程中提前切入。
