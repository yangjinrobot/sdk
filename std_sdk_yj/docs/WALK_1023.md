# 1023 拟人行走

> 2026-10-26：NirenWalk 默认模型已替换为 [1026 run](NIRENWALK_1026.md)。以下记录为旧版本。

NirenWalk 状态加载 `policy/1023/policy_11500.onnx`，安装后路径为
`/opt/robot/share/motion_master/policy/1023/policy_11500.onnx`。

按提供的 `dr02_2gun_amp_dt_walk_env.py`，单帧观测依次为角速度 3、投影重力 3、
实际速度指令 3、moving_flag 1、关节位置减默认角 21、关节速度 21、上一动作 21，
共 73 维。不传入步态相位。moving_flag 在平移指令模长 > 0.15 或转向指令绝对值
> 0.15 时为 1，否则为 0。输入为从旧到新的 5 帧历史再加当前帧，共 438 维；
最新历史帧包含当前帧。进入状态清空上一动作，首个观测填满历史。

从 RL 或 RL Stand 切入 NirenWalk 时，从上一状态最后下发的手臂指令开始，
用 1 秒 smoothstep 曲线过渡到实时策略输出。双臂的 kp、目标位置、kd、目标速度、
前馈力矩五列均参与过渡；腰腿直接使用策略输出。每次重入重新捕获起始指令。
上一指令无效时进入阻尼状态。

双肘默认角按用户指定设为 +1.2 rad，同时用于关节位置观测偏差和动作目标角基准。
env 中的具体参数来自外部 cfg，当前未提供该模型的配套 cfg。其余默认关节角、
PD、动作缩放 0.25、关节速度缩放 0.05、动作裁剪 ±10、观测裁剪 ±100 和速度范围
沿用原 NirenWalk 设置（X [-0.5, 1.5]、Y ±0.6、Yaw ±1）。
这些参数尚未与 1023 训练配置核对。策略周期维持 20 ms。

离线验证：`python tests/test_1023_policy.py`，需要 g++、numpy、onnxruntime。
覆盖真实模型推理、观测顺序、历史滚动与重入、上一动作、关节映射及 moving_flag
边界。离线验证不包含实机运行或训练 cfg 参数一致性检查。
