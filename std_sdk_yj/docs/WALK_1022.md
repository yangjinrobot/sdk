# 1022 持枪 / 拟人行走

> 2026-10-22：已按要求恢复有步态版本，默认持枪为 `std_amp_2.onnx`，拟人为 `amp_dt/amp_dt.onnx`。以下无步态模型保留但不再默认加载。

RLControlMode 使用 `policy/1022/policy_18000.onnx`；NirenWalk 使用
`policy/1022/policy_17000.onnx`。历史模型位于项目根目录 `policy/1022/`，
由现有安装规则递归打包到 `/opt/robot/share/motion_master/policy/1022/`。
配套 `env.yaml`（持枪）和 `env_nirenxingzou_1020.yaml`（拟人）一并保存。
C++ 使用同步后的常量，运行时不解析 YAML。

单帧观测依次为：机身角速度 3、投影重力 3、实际速度指令 3、
策略关节顺序的位置减默认角 21、关节速度乘 0.05 共 21、上一帧裁剪后动作 21。
共 72 维，不包含 sin/cos、phase 或 air ratio。
输入按历史从旧到新 5 帧再加当前帧拼接，共 432 维；最新历史帧也包含当前帧。
进入状态时上一动作清零，首个有效观测重复填满历史；每次重入重新初始化。

两个模型均输出 21 维动作，目标角为默认角 + 0.25 × 动作。
动作裁剪 ±10，观测裁剪 ±100，保持原有关节映射。
双肘默认角：持枪 -0.2 rad，拟人 +1.2 rad。肩 yaw 的 kp 为 100，
其余默认角和 PD 亦按对应 YAML 同步。

归一化输入限幅 ±1；持枪实际速度范围 X [-0.5, 1.5] m/s、Y ±0.6 m/s；
拟人为 X [-0.5, 1.2] m/s、Y ±0.5 m/s，两者 Yaw 均为 ±1 rad/s。
已取消约 2 秒入场零速等待；保留速度增量限制、手臂入场过渡和状态安全退出。
策略运行 50 Hz，控制循环每 20 次更新策略。

离线验证（需要 g++、numpy、PyYAML、onnxruntime）：

```bash
python tests/test_1022_policy.py
```

测试各模型 280 帧，包括重入、首帧历史、滚动历史、上一动作、关节输出映射，
并独立读取 YAML 对比参数，用 Python ONNX 对比 C++ 观测及动作。
旧 78 维兼容回归仍可运行 `tests/test_nirenwalk_amp_dt.py`。
这些检查不连接机器人，不代表实机步态验证。
