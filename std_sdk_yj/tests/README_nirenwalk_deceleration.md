# AmpControl_Walk2Run_Mode 高速 S 曲线减速

仅 AmpControl_Walk2Run_Mode 的前后速度指令启用，其他策略、侧移和转向沿用原有斜坡。
进入策略或退出策略时清空减速状态。

- 触发条件：当前送给策略的前后速度指令绝对值 **大于 1 m/s**，并请求向零方向降速或反向。
- 触发后持续平滑跟踪到目标，不在经过 1 m/s 时退出；中途改变目标保留当前减速状态。
- 默认限制：激活期间加速度绝对值 1.0 m/s²，jerk 3.0 m/s³。参数位于
  `run_policy/cr1/include/nirenwalk_deceleration.h`。
- 从匀速 2 m/s 松杆回零，指令约 2.34 s 到零；1.2 → 0.5 m/s 约 1.04 s。
- 平滑作用于速度指令，实际机器人减速效果仍取决于策略跟踪能力。
  停止时间和距离增加，需先仿真，再低速实机确认。
- 这里的 jerk 限制作用于触发后的 S 曲线段；触发前的普通加速仍是原有斜坡。
- 减速中突然改变目标时，优先保持加速度连续，可能暂时越过新目标再收敛。
- 失控/急停仍由 AmpControlWalk2RunModeState 立即切换阻尼；本功能不延迟状态切换。
  直接调用 runner 的 safe_control_mode 请求跳过 S 曲线，保留原有安全指令逻辑。
- moving flag 仍使用原有阈值，并由最终平滑后的指令生成。

离线验证（不连接机器人）：

```bash
python3 tests/test_nirenwalk_deceleration.py
```

覆盖固定目标的单调减速、跨零反向、途中重推/连续变动目标、减速度和 jerk 限制，
以及当前 1028 ONNX 模型的最终观测指令、侧移/转向斜坡、低速行为、重新进入和安全绕过。
